PeakLogic Cloud — SaaS install (port 3100)
==========================================

Primary deployment for peaklogic.io: multi-tenant login, Studio, CMMS.
Uses DigitalOcean Managed MongoDB (not local mongod).

Phase 1 (two droplets + archive): deploy/cloud/phase1/WINSCP-DEPLOY.md
Architecture: docs/CLOUD_DEPLOY_DO_PHASE1.md

Optional later: edge runtime on port 3090 (enable-runtime-3090.sh)

Quick install — Phase 1 (WinSCP)
--------------------------------

1. Build bundles (Windows, from est-pc):

     cd C:\Users\public\data\est-pc
     powershell -ExecutionPolicy Bypass -File scripts\create-phase1-bundles.ps1

     Output:
       dist\peaklogic-cloud-YYYYMMDDd.tgz   → cloud-1-saas droplet
       dist\peaklogic-archive-YYYYMMDD.tgz  → cloud-2-archive droplet

2. WinSCP: upload each .tgz to /tmp/ on the matching droplet.

3. Follow deploy/cloud/phase1/WINSCP-DEPLOY.md (archive droplet first, then SaaS).

4. Config templates (copy to /etc/peaklogic/ before install scripts):

     deploy/cloud/phase1/droplet-saas/saas.env.template
     deploy/cloud/phase1/droplet-saas/mqtt.env.template
     deploy/cloud/phase1/droplet-saas/archive-compact.env.template
     deploy/cloud/phase1/droplet-archive/archive.env.template

5. Allowlist SaaS droplet PUBLIC IP on DO Managed MongoDB (Trusted sources).

6. Seed demo tenant (once, after secrets are set):

     sudo -u peaklogic bash -lc 'cd /home/peaklogic && npm run seed'

7. TLS:

     certbot --nginx -d peaklogic.io -d www.peaklogic.io

8. Verify:

     curl -s http://127.0.0.1:3100/health
     curl -sI https://peaklogic.io/login
     systemctl status peaklogic-saas nginx

Single-droplet SaaS only: docs/CLOUD_DEPLOY_DO.md

Firewall: 22, 80, 443, 8883 (MQTT). Archive 8090 — VPC private only.
Do not expose MongoDB port 27017.

Demo login (after seed): org `demo`, `operator@demo.local` / `demo`
Platform admin: `admin@demo.local` / `ChangeMeAdmin!`
