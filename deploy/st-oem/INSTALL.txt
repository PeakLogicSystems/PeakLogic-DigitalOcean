MV-ST-OEM — USB install kit
============================

Copy this entire folder to the target device (OpenWrt router, Raspberry Pi, or Linux PC).

Contents
--------
  peaklogic-st-oem/     Node runtime + web UI (program, tags, drivers, I/O map)
  peaklogic-st-oem/sdk/ C++ SDK for OpenWrt OEM daemons (production target)
  peaklogic-st-oem/hal/ Pi SM-I-001 HAL plugin sources (bench / optional I/O)
  peaklogic-st-oem/docs/OPENWRT.md   OpenWrt deployment (primary)
  peaklogic-st-oem/docs/HAL.md       HAL driver reference

Quick install — Raspberry Pi / Linux (systemd)
-----------------------------------------------
  cd peaklogic-st-oem
  npm install
  npm run build-native          # required for SM-I-001 HAL plugin only
  sudo cp deploy/peaklogic-st-oem.service /etc/systemd/system/
  sudo systemctl enable --now peaklogic-st-oem

  Open http://<device-ip>:3090

Quick install — OpenWrt (production)
------------------------------------
  See peaklogic-st-oem/docs/OPENWRT.md

  Summary:
    1. opkg install node (enable CONFIG_PACKAGE_node=y in build)
    2. Copy peaklogic-st-oem to /opt/peaklogic-st-oem
    3. cd /opt/peaklogic-st-oem && npm install --production
    4. Set PEAKLOGIC_DATA=/etc/peaklogic, PORT=3090
    5. Start via procd/init (use deploy/peaklogic-st-oem.service as template)
    6. Cross-compile OEM C++ apps: sdk/ + toolchain-openwrt.cmake
       MV_HOST=127.0.0.1 MV_PORT=3090

Environment
-----------
  PEAKLOGIC_PRODUCT=st-oem
  PEAKLOGIC_DATA=./data          (use /etc/peaklogic on routers)
  PORT=3090
  MV_HOST=127.0.0.1              (SDK clients)
  MV_PORT=3090                   (SDK clients)
